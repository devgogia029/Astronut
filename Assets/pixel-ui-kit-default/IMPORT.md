# IMPORT - Pixels - Pixel Art UI Kit

Native grid: **varies per piece; panels 32 x 32, bars 32 x 8, cursors 16 x 16 (1x-4x)**

37 pieces in 6 categories, 4 scales, plus a 9-slice atlas description.

    png/<scale>x/<category>/<name>.png
    categories: Button Cursor Gauge Icon Panel Slot
    metadata/atlas.json    base_size + 9-slice insets in 1x pixels, per piece
    metadata/pieces.csv    the flat list

## Godot 4.x

1. Copy `png/1x/` into `res://ui/`.
2. Project Settings > Rendering > Textures > **Default Texture Filter = Nearest**.
3. Use `StyleBoxTexture` for the 9-slice pieces: create the StyleBox, assign the
   PNG, then set **Texture Margins = Left/Top/Right/Bottom** from `atlas.json`
   (`insets_1x`). Margins are in 1x pixels; multiply by your scale if you draw the
   piece bigger.
4. `TextureProgressBar` for `bar-health-*`, `bar-mana-*`, `bar-stamina-*`,
   `bar-xp-*`: assign the filled and empty files to **Under** and **Over**, set
   **Fill Mode = Left to Right**.
5. Cursors: Project Settings > Display > Mouse Cursor > **Custom Image**, set the
   hotspot in integer pixels.
6. Draw the whole UI at an integer scale (`stretch_mode = canvas_items`, integer
   scale on the root viewport) or 1 px lines will turn to 2 px mush.

## Unity 2022.3 LTS

1. Copy `png/1x/` into `Assets/UI/`.
2. Select all: **Texture Type = Sprite (2D and UI)**, **Sprite Mode = Single**,
   **Pixels Per Unit = 16**, **Filter Mode = Point**, **Compression = None**,
   **Generate Mip Maps = off**. Apply.
3. For 9-slice pieces, in the Sprite Editor set **Border** to the `insets_1x`
   values from `atlas.json`, then in the `Image` component set
   **Image Type = Sliced** and **Pixels Per Unit Multiplier = 1**.
4. Bars: use `Image` with **Image Type = Filled**, **Fill Method = Horizontal**,
   **Fill Origin = Left**.
5. Cursors: **Edit > Project Settings > Player > Default Cursor** or
   `Cursor.SetCursor(texture, hotspot, CursorMode.Auto)` with a bottom-left hotspot
   in pixels.

## How these files were made

Everything here is generated by original Python code (Python 3, numpy, Pillow)
written for this shop. There is no stock art, no tracing, no photo texture, no
scanned material and no third-party asset in any of it.

The generator code was written with AI assistance, so the store's listings
declare generative AI assistance for graphics. The output itself is ordinary
deterministic pixel/vector art: fixed grid, fixed palette per material, no
image-model output.

Practical consequence for you: nothing here is hand-painted, so it is stylistically
consistent and very cheap to recolour, but it is also more regular than a hand-drawn
set. Neutrals and keywords ("fantasy icons", "sci-fi HUD") are what it does best.

## Known limitations

This is a small kit: several pieces are 1 px outlines around an empty rectangle
(`panel`, `slot-empty`, `dialog`), which is what a UI kit needs but it means the
visual interest is low out of the box. It is designed to be recoloured and to have
your own content placed inside the frames.
